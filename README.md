## ~/.config

The `config/` directory holds backups of `~/.config` app configs. Each app
directory is symlinked back into `~/.config`, so edits land in this repo
automatically:

```sh
ln -s ~/projects/dotfiles/config/<app> ~/.config/<app>
```

Backed up: `hypr`, `waybar`, `wallust`, `rofi`, `ghostty`, `btop`, `cava`,
`swaync`, `swappy`, `nwg-displays`, `waybar-weather`.

Intentionally excluded (see `.gitignore` / not linked):
- `config/waybar-weather/{geolocation,cityname}` — private location data
- `config/hypr/monitors.conf` — machine-specific, auto-generated by nwg-displays
- `zsh/plugins`, `mise`, `xfce4` — vendored deps / runtime state

Note: `hypr/*.conf` hardcode `/home/nyx/...` paths; adjust on restore if the
username differs.

## opencode

`opencode/` is tracked at the top level rather than under `config/`, because only
two files are linked (not the whole directory — the rest of `~/.config/opencode`
is runtime state):

```sh
ln -sfn ~/projects/dotfiles/opencode/opencode.jsonc ~/.config/opencode/opencode.jsonc
ln -sfn ~/projects/dotfiles/opencode/cli.json       ~/.config/opencode/cli.json
```

See [`opencode/README.md`](opencode/README.md) for the full setup runbook,
including the CLIProxyAPI gateway that backs Anthropic.
